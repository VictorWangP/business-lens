# 模型配置技术设计

更新：2026-10-15。本文档说明智能问数系统中的“模型配置（Model Settings & Provider Integration）”技术架构、OpenAI 兼容协议发现探针、多模型类型（LLM / Embedding）分流、敏感密钥对称加密与脱敏防护。

## 1. 业务目标与架构原则

数据问答系统依赖大语言模型（LLM）进行意图理解、NL2SQL 生成、多轮规划与数据洞察，向量模型（Embedding）用于常问问题的候选分组匹配。当前版本已移除文档分片、知识库索引与检索链路。
- **开放多模型接入（OpenAI-Compatible Standard）**：全面拥抱标准的 OpenAI 接口契约，无缝支持阿里云百炼（DashScope）、DeepSeek、OpenAI、Ollama、vLLM 以及企业自建推理网关。
- **动静结合的自动模型发现**：支持一键连通性测试与 `/v1/models` 自动拉取；在对端网关未开放列表接口时，支持灵活手动录入模型 ID。
- **敏感凭证深度安全防护**：存储阶段实施对称强加密，API 响应阶段一律脱敏为 `********`，Base URL 变更时强制重置 Key，防范凭据走私与泄漏。
- **功能职责明确分流**：区分 `type="llm"` 与 `type="embedding"`，并支持全局配置默认主对话模型与默认向量模型。

## 2. 总体架构与数据流

```text
[ 前端模型配置界面 (ModelEditor.tsx) ]
        │
        ├─ 输入 Base URL、API Key、Provider 标识
        ├─ 点击「测试连接」/「拉取可用模型」
        │       │
        │       ▼ (POST /settings/model-provider/models)
        │ [ 1. URL 规范化与安全校验 (禁止账号、片段与非法 scheme) ]
        │ [ 2. 若 API Key 为 '********'，按 credential_model_id 解密复用旧 Key ]
        │ [ 3. 调用 AsyncOpenAI(base_url, api_key).models.list() 探测 ]
        │ [ 4. 自动捕获 401/403/404/429 并给出精准运维诊断提示 ]
        │       │
        │       ▼ 返回模型 ID 列表并自动填入下拉选单
        ▼
[ 点击「保存模型设置」 (PUT /settings/app-config) ]
        │
        ├─ 后端识别新增或修改的 API Key，执行 encrypt() 密文加密
        ├─ 若 Key 为 '********' 则沿用原有密文
        ├─ 持久化至 app_configs (config_key='model_setting')
        ▼
[ 运行时加载 (LLMService / EmbeddingProvider) ]
        │ 读取配置，通过 decrypt() 解密真实密钥，构造异步客户端
```

## 3. 数据模型与凭证安全

### 3.1 配置持久化结构（AppConfig）

在 `app_configs` 表中以 JSON 文本存储在 `config_value` 字段：

```python
class ModelItem(BaseModel):
    id: str                                  # 模型标识 (如 qwen3.5-plus, text-embedding-v3)
    name: str                                # 界面展示别名
    provider: str                            # 供应商标识 (如 阿里云百炼, DeepSeek, Ollama)
    base_url: str                            # 接口基准地址
    api_key: str | None = None               # 对外下发为 '********'，存库为密文
    type: Literal["llm", "embedding"] = "llm"# 模型类型
    context_window: int | None = None        # 上下文窗口上限 (如 1,000,000)
    max_output_tokens: int | None = None     # 单次生成上限 (如 8,192)

class ModelSettingConfig(BaseModel):
    is_enabled: bool = True
    default_model: str = ""                 # 注册后显式配置
    default_embedding_model: str | None = None  # 常问分组模型，无内置模型
    temperature: float = 0.7                 # 默认采样温度
    available_models: list[ModelItem] = []   # 用户可用模型列表
```

### 3.2 敏感信息防御三大铁律

1. **出库强制脱敏（Sanitization on Egress）**：
   在 `GET /settings/app-config` 序列化时：
   ```python
   item["api_key"] = "********" if item.get("api_key") else None
   ```
   前端、浏览器开发者工具网络面板及页面状态中绝对不留存任何明文 API Key。
2. **入库对称加密（Encryption on Ingress）**：
   在 `PUT /settings/app-config` 接收保存时：
   - 若传入的新 Key 为真实有效字符串，经 `app/infrastructure/credentials.py` 的 Fernet/AES 算法生成密文存储。
   - 若传入 `'********'` 且未改动所属模型的 `base_url`，后端安全复用原密文，避免重复录入。
3. **篡改与地址变更防护（URL Change Protection）**：
   当用户在前端更改了某模型的 `base_url`，必须强制清空 Key 并要求重新录入，严禁直接复用旧 Key 发送至新 URL，杜绝跨域钓鱼泄露凭证风险。

## 4. 模型探针与异常诊断机制（app/services/model_provider.py）

系统在 `list_provider_models` 中封装了工业级的健壮性检测：

```python
async def list_provider_models(base_url: str, api_key: str) -> list[str]:
    # 1. URL 格式防注入校验
    url = urlsplit(base_url.strip().rstrip('/'))
    if url.scheme not in {'http', 'https'} or not url.hostname or url.username or url.password or url.query:
        raise ValueError('请输入有效的 HTTP(S) Base URL，不要包含账号、查询参数或片段')
    
    # 2. 超时截断与连接尝试
    async with asyncio.timeout(20):
        async with AsyncOpenAI(base_url=base_url, api_key=api_key, timeout=15, max_retries=0) as client:
            page = await client.models.list()
            return sorted({m.id for m in page if isinstance(m.id, str) and m.id.strip()})
```

### 4.1 细分错误诊断表

| 触发异常 | HTTP 状态 | 用户端诊断说明 |
| :--- | :---: | :--- |
| `APIStatusError (401/403)` | 422 | 供应商认证失败，请检查 API Key 和访问权限 |
| `APIStatusError (404)` | 422 | 供应商未提供模型列表接口，请检查 Base URL，或手动填写模型 ID |
| `APIStatusError (429)` | 422 | 供应商请求限流或配额不足，请稍后重试 |
| `APIConnectionError` | 422 | 无法连接供应商，请检查 Base URL、网络和证书 |
| `TimeoutError` | 422 | 连接超时，请检查 Base URL 和网络 |
| 其他状态码 | 422 | 供应商接口请求失败（HTTP {status_code}） |

## 5. 运行时模型参数与容量适配

系统运行时，`app/agents/limits.py` 结合模型配置中的上下文参数协同工作：
- **容量识别**：若模型 ID 包含 Qwen 3.7 / 3.8 等官方百炼商用型号，自动识别为 1,000,000 上下文与 991,808 输入容量；其他第三方模型自动根据配置中的 `context_window` 适配，默认 131,072。
- **输出预留**：单次模型输出根据配置中的 `max_output_tokens` 预留空间（默认 8,192 tokens），防止长推理任务因剩余上下文不足被非预期截断。
