# 前端开发指引

本规则适用于 `frontend/` 下的开发、功能调整和 UI 重构。本文件是前端规则的唯一正式入口。

## UI 组件优先级

1. 聊天交互优先使用 assistant-ui 原生组件和公开 API，包括消息列表、消息内容、输入框、发送与停止生成、工具展示及运行状态。先检查项目安装版本和官方文档，通过组合、属性和样式定制满足需求。
2. 通用 UI 优先使用 shadcn/ui，包括弹窗、表单控件、选择器、开关、菜单、确认框、提示和布局组件。shadcn/ui 已由用户批准为 assistant-ui 未覆盖场景的首选方案，无需针对这些用途重复询问。
3. 引入组件时使用官方来源，优先复用 `src/components/ui/`，保持 React、Tailwind CSS 版本兼容和明暗主题一致；不得仅为添加组件随意升级整个技术栈。
4. 只有确认 assistant-ui 和 shadcn/ui 都没有适用组件时，才向用户说明缺失组件及用途，并询问用户提供备用方案。用户明确回复前，不得自行决定引入其他组件库或重新实现通用 UI；不依赖该方案的其他工作可以继续。
5. 既有且已获授权的业务专用组件（如 Recharts 图表、业务指标、查询证据）可继续维护，并与原生组件组合。组件替换必须保留模型配置、SSE 流式响应、停止生成、会话切换、Markdown、图表和来源引用等已有功能。
